# 🎙 ИИ-секретарь созвонов (meeting-secretary-bot)

Telegram-бот: присылаешь аудио/видео созвона — получаешь **стенограмму с репликами
спикеров, саммари, решения и задачи** в Telegram + .docx. Русский язык.

```
Клиент → Telegram → api.telegram.org → SOCKS5-туннель → бот (Коренёво)
   → AssemblyAI (транскрипт + диаризация спикеров)
   → DeepSeek (саммари, решения, задачи — JSON-инструкция)
   → Отчёт в TG (HTML) + .docx
```

## Быстрый старт (dev)

```bash
python -m venv .venv && .venv/Scripts/activate    # Windows
pip install -e ".[dev]"
cp .env.example .env                              # заполни ключи
python -m secretary.bot
```

## Структура

```
src/secretary/
├── bot/       # aiogram 3: приём медиа, /start, /orders, очередь
├── stt/       # STTProvider-абстракция + AssemblyAI (диаризация)
├── llm/       # DeepSeek: саммари/решения/задачи (JSON)
├── report/    # отчёты: TG HTML + .docx + полная стенограмма
├── storage/   # SQLite: orders (+ clients/packages для v1.1)
├── worker/    # asyncio-пайплайн: скачать → STT → LLM → отчёт
└── api/       # FastAPI: /health, /api/orders, мини-кабинет (v2.0-фундамент)
```

## Ограничения v1.0.0

- Файлы до 20 МБ (лимит Bot API); >20 МБ — v1.1.0 (Local Bot API Server) или ссылка.
- Онлайн-STT (AssemblyAI): ~$0.23/час с диаризацией; данные уходят в облако —
  дисклеймер в отчёте. РФ-провайдер — v1.3.0.
- Файлы и записи хранятся 7 дней (`RETENTION_DAYS`), затем удаляются.
